The workspace grows with the questions you ask.

01

Understand a week

Ask about a bounded date range. See which records and sources support an answer, and where context is missing.

02

Keep records useful

Review a planned record change before granting a write. Retried requests should not create duplicate entries.

03

Find the problem

Distinguish an unavailable source from an empty result. Keep last-known data visible with honest freshness.

04

Make it fit you

Request a view, metric, integration or workflow. Keep its source, tests and maintenance notes in your own workspace.

Built for a second agent, too

Your next change should not depend on remembering a chat.

Codex and Claude Code are intended to discover the same versioned interfaces and persistent personal workspace. One agent can add a feature; another can understand and maintain it from its source, tests and notes.

Supported extensions live outside replaceable releases. Deeper core changes need a tracked fork, a deliberate rebase and tests. Arbitrary edits are not promised automatic upgrades.
