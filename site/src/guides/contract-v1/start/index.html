Contract v1 guide · installation is not available

Prepare your host.

Understand the prerequisites and consent steps before anything changes.

Readiness only. Contract version 1.0.0 is a design reference, not a released product version. There is no verified installer or downloadable runtime. Review release gaps.

Planned host targets

An already-running 64-bit Linux x86-64 host or ARM64 Raspberry Pi is the target. Supported OS versions, minimum memory and storage, and physical Pi qualification have not been established. Architecture alone is not proof of compatibility. Preparing a bare Pi or its OS is outside v1.

The agent may run on a different host. Native Windows server support is not established. Kubernetes and Postgres are not mandatory parts of the v1 design.

What you will approve yourself

  1. Private connectivity. The host and clients join your owner-controlled Tailscale network. HTTPS reachability, clocks and access policy need a preflight check.
  2. Application sign-in. Tailscale membership alone does not grant access to health data. Owner setup and application credentials remain separate.
  3. Agent grants and sharing. Select the read/write capabilities and context your agent may use. Review the records that could go to its AI provider.
  4. Optional sources. Choose integrations and their permissions. Phone Health access and pairing are separate explicit steps; there is no distributed companion release here.
  5. Changes to the host. Review a plan tied to a real pinned release before approving installation or account changes.

What a future install guide must identify

A verified release needs an immutable manifest, runtime/package and installer references with digests, matching source and guide versions, compatibility evidence and an exact host support matrix. Commands must match those artifacts. These pages intentionally provide no installation command.
